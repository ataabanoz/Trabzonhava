# TrabzonHava v1
Özel kullanım için PWA prototipi. Ana ekran, Harita, Radar, Kar Modu, Yıldırım, Deniz/Balıkçı, Kameralar, Trafik, Doğa Atlası ve Geçmişe Git modlarının uygulama iskeletidir.

## Çalıştırma
Klasörde `python3 -m http.server 8080` çalıştırıp tarayıcıdan localhost:8080 açın.

## Sonraki üretim adımı
MGM/deniz/radar veri kaynakları, belediye kameraları, topoğrafik harita, kimlik doğrulama ve özel HTTPS dağıtım eklenmelidir. Üçüncü taraf veri ve görüntüler kullanım şartlarına uygun bağlanmalıdır.
